Фронтенд: интерактивная схема

Интерактивная электротехническая схема, где каждое действие влияет на состояние элементов:

  • Точки, сопротивления, контакты
  • Пересчёт до стабильного результата
  • Реальное время, а не «статичная картинка»

Действие → Состояние → Пересчёт → Обновление UI

Фронтенд: realtime и устойчивость

WebSocket-слой с контролем соединения:

  • 🔄 Auto-reconnect (переподключение)
  • 📦 Message queue (очередь сообщений)
  • 💾 State recovery (восстановление состояния)

Сервер → WebSocket Manager → Redux → UI

Фронтенд: архитектура состояния

Redux-слайсы по доменным зонам:

Simulation | Circuit | Timer | Modals | Progress

  • Сохранение критичных данных между сессиями

Login → Scenario → Simulation → Complete → Analytics

Бэкенд: серверная архитектура

Поддержка запуска и сопровождения симуляций:

  • 🌐 REST API — управляемые операции (Auth, Scenarios, Results)
  • ⚡ WebSocket — realtime-события (Simulation events, Updates)
  • 🔐 Модель ролей и контроль доступа

Дизайн: UX для безопасности

Дизайн для безопасности, а не декоративности. 4 принципа:

  • 👁️ Фокус внимания — приоритетные зоны
  • 🚦 Контраст состояний — норма / предупреждение / авария
  • 🔁 Предсказуемость — единые паттерны
  • 📱 Адаптивность — читаемость на любых экранах
