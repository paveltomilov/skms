Настоящий документ описывает план тестирования фронтенд-приложения SMS-SET (система моделирования и обучения).

## 5. E2E ТЕСТИРОВАНИЕ

### 5.1 Сценарий: Полный путь студента

```
1. Открыть страницу /login
2. Ввести валидные данные
3. Нажать "Войти"
4. Проверить переход на /ptk
5. Подождать загрузки симуляции
6. Найти все неисправности
7. Нажать "Завершить"
8. Проверить переход на /simulation/{id}/stats
9. Проверить отображение статистики
```

### 5.2 Сценарий: Полный путь преподавателя

```
1. Открыть страницу /login
2. Ввести данные преподавателя
3. Проверить переход на /training
4. Просмотреть список студентов
5. Проверить статистику
```

### 5.3 Сценарий: Восстановление пароля

```
1. Открыть страницу /login
2. Перейти на восстановление
3. Ввести email
4. Проверить получение кода
5. Ввести код и новый пароль
6. Проверить вход с новым паролем
```

### 5.4 Сценарий: Ролевой доступ

```
1. Войти как админ → проверить доступ к /ptk
2. Войти как студент → проверить доступ к /ptk
3. Войти как преподаватель → проверить доступ к /training
4. Попытаться перейти на чужую страницу → редирект
```
