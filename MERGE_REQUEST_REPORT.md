# Отчёт по изменениям: Обновление попапов завершения и остановки симуляции

## Описание

Обновлены попапы завершения и остановки симуляции с добавлением функциональности для работы с тарифными планами и улучшением UX.

## Изменённые файлы

### 1. `src/widgets/PopupSimulationComplete/index.tsx`

**Изменения:**

-   Добавлена поддержка тарифных планов через хук `useSubscription`
-   Добавлены две кнопки:
    -   Основная кнопка: "Пройти опрос" (для free плана) или "Узнать результат" (для paid плана)
    -   Кнопка "Менять план"
-   Обработчики кнопок выводят предупреждения в консоль (временная реализация)
-   Текст сообщения: "Вы закончили, что бы узнать результат пройдите опрос"

**Функциональность:**

-   По умолчанию используется план `free`
-   Кнопки отображаются внизу попапа
-   Текст сообщения отображается по центру

## Технические детали

### Тарифные планы

-   По умолчанию используется план `free`
-   План определяется через cookie `subscription_type`
-   Поддерживаются планы: `free` и `paid`

### Временные обработчики

Обработчики кнопок в `PopupSimulationComplete` используют `console.warn`:

-   Основная кнопка: `console.warn('редирект на страницу опроса')`
-   Кнопка "Менять план": `console.warn('менять план')`

**Примечание:** Эти обработчики должны быть заменены на реальную логику при интеграции с бэкендом.

## Тестирование

⚠️ **Важно:** Проверки в `handleFinishSimulation` временно закомментированы для тестирования. Необходимо раскомментировать перед мерджем в основную ветку.
